# Streamlit 간단한 계산기 (Simple Calculator)

Streamlit을 활용하여 두 정수와 연산자를 입력받아 계산 결과를 출력하는 웹 애플리케이션입니다.

## 📌 주요 기능
- **직관적인 UI**: 첫 번째 정수, 연산자, 두 번째 정수를 순서대로 입력
- **지원 연산자**: 사칙연산(`+`, `-`, `*`, `/`) 지원
- **예외 처리 및 오류 안내**:
  - 정수가 아닌 값 입력 시 오류 메시지 표시
  - 지정된 연산자 외 입력 시 오류 메시지 표시
  - 0으로 나눌 경우 오류 메시지 표시

---

## 🛠️ 설치 및 실행 방법

### 1. 패키지 설치
필요한 패키지를 `requirements.txt`를 통해 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 앱 실행
다음 명령어로 Streamlit 애플리케이션을 실행합니다.

```bash
streamlit run app.py
```
*(파일명이 `app.py`가 아닌 경우 해당 파일명으로 변경하여 실행해 주세요.)*

---

## 💻 사용 예시

1. **첫 번째 정수** 입력란에 정수 입력 (예: `10`)
2. **연산자** 입력란에 `+`, `-`, `*`, `/` 중 하나 입력 (예: `+`)
3. **두 번째 정수** 입력란에 정수 입력 (예: `5`)
4. 입력이 완료되면 화면 하단에 계산 **결과**가 표시됩니다.
