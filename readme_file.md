# 🎲 Streamlit 로또 번호 생성기

Streamlit을 기반으로 만든 간단하고 직관적인 로또 번호 생성기 애플리케이션입니다.

## 📌 주요 기능
- **로또 번호 생성**: 1부터 45까지의 숫자 중 중복 없이 6개 번호를 무작위로 추출합니다.
- **최대 5게임 기록**: 버튼을 누를 때마다 생성된 번호 세트가 누적되며, 최대 5개까지 화면에 표시됩니다 (5개 초과 시 가장 오래된 세트 자동 삭제).
- **실제 로또 공 색상 적용**: 번호 구간별로 실제 로또 공과 동일한 색상을 시각적으로 제공합니다.
  - 🟡 1 ~ 10: 노란색
  - 🔵 11 ~ 20: 파란색
  - 🔴 21 ~ 30: 빨간색
  - ⚪ 31 ~ 40: 회색
  - 🟢 41 ~ 45: 초록색

---

## 🛠️ 설치 및 실행 방법

### 1. 필수 패키지 설치
`requirements.txt` 파일을 사용하여 필요한 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
다음 명령어로 Streamlit 앱을 실행합니다.

```bash
streamlit run app.py
```
